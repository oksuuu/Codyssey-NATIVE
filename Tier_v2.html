이 영화를 어디에 놓을까요?

TMDB 연결 설정

기본 모드는 내장 영화 목록으로 인터넷 없이 동작합니다. 전체 영화 검색과 TMDB 추천을 사용하려면 API 키가 서버에 보관된 Cloudflare Worker의 기본 주소를 입력하세요. API 키는 이 파일에 넣지 않습니다.

Worker는 TMDB 경로와 쿼리를 그대로 전달하고, 파일에서의 요청을 허용하도록 CORS 응답 헤더를 제공해야 합니다.

GET /search/movie?query=...&language=ko-KR
GET /movie/{id}/recommendations?language=ko-KR
GET /movie/{id}/similar?language=ko-KR

추천은 TMDB의 추천·유사 영화 목록을 사용합니다. 포스터는 연결 시 TMDB에서 불러옵니다. 이 제품은 TMDB API를 사용하지만 TMDB의 승인이나 인증을 받지 않았습니다.
